# Andrew Ayad — CV

This repository holds the latest version of Andrew Ayad's CV.

## Files

| File | Description |
|------|-------------|
| [Andrew_Ayad_CV.pdf](Andrew_Ayad_CV.pdf) | CV in PDF format, ready to view or download |
| [Andrew_Ayad_CV.docx](Andrew_Ayad_CV.docx) | Editable Word version of the CV |

## Usage

- To view the CV, open the PDF file directly on GitHub or download it.
- To make changes, edit the `.docx` file, then export a new PDF and commit both files.
